# 🖤 Brutalist To-Do
 
a to-do list that looks like it was carved out of concrete. big borders, black & white, zero chill.

## Note: first draft, duct-taped into shape by me and my AI. it's not much of optimized, but if it work, it works 😎
 
**Live:** https://vwii.github.io/todo-list/
 
## what's in it
 
- add, check off, and delete tasks
- loud brutalist design (high contrast, thick borders, no soft stuff)
- custom magnetic cursor that snaps onto buttons like it's got a crush on them
- smooth scrolling with Lenis
- works on desktop and mobile
## built with
 
React + TypeScript + Vite + Tailwind + Motion + Lucide icons
 
## run it yourself
 
```bash
git clone https://github.com/vwii/todo-list.git
cd todo-list
npm install
npm run dev
```
 
build it:
 
```bash
npm run build
```
 
## deploy
 
push to `main` and GitHub Actions builds it and puts it on GitHub Pages. that's it, don't touch anything. or however you want to deploy it 🤷
